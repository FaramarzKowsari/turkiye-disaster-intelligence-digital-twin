# Apply this patch with GitHub Desktop

1. Open your local folder:
   `turkiye-disaster-intelligence-digital-twin`
2. Extract the contents of this patch directly into that folder.
3. Allow Windows to merge folders if prompted.
4. Open GitHub Desktop.
5. Confirm that the new files appear under **Changes**.
6. Use commit message:
   `Complete research-grade starter scaffold`
7. Click **Commit to main**.
8. Click **Push origin**.

Expected additions include:
- pyproject.toml
- LICENSE
- CITATION.cff
- .gitignore
- .github/workflows/ci.yml
- docs/*
- tests/*
- src/turkiye_disaster_twin/*
