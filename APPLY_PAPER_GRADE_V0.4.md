# Apply paper-grade pipeline v0.4

1. Extract this ZIP directly into the repository root.
2. Allow replacement of `pyproject.toml`.
3. Open GitHub Desktop.
4. Commit with:

   `Add paper-grade benchmark and statistical inference pipeline`

5. Push origin.
6. Wait for normal CI to turn green.

After CI is green, you will see a new workflow:

**Actions → Research Benchmark**

Run it manually to create 100, 500 or 1000-realisation research artifacts.

The normal CI does not automatically run large OSM/Monte Carlo campaigns.
