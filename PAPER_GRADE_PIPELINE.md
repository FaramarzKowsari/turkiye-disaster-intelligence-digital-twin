# Paper-Grade Research Pipeline / Makale Düzeyinde Araştırma Hattı / Flujo de Investigación con Calidad de Publicación

## English

The v0.4 research pipeline runs large paired Monte Carlo campaigns separately from the public
web application. GitHub Actions can execute 100, 500 or 1000 realisations per disruption level
and returns CSV, Parquet, JSON metadata and SHA-256 checksums as a downloadable research artifact.

Inference is based on matched Greedy-versus-Global observations and includes bootstrap confidence
intervals, paired sign-flip permutation tests, Holm-adjusted p-values, paired effect size and
algorithm win rate.

The network disruption and emergency demand layers remain synthetic research stress tests, not
official earthquake damage or casualty forecasts.

## Türkçe

v0.4 araştırma hattı, büyük eşleştirilmiş Monte Carlo deneylerini halka açık web uygulamasından
ayırır. GitHub Actions her kesinti şiddeti için 100, 500 veya 1000 gerçekleşme çalıştırabilir ve
CSV, Parquet, JSON meta verisi ile SHA-256 sağlama toplamlarını indirilebilir bir araştırma
çıktısı olarak üretir.

İstatistiksel çıkarım aynı senaryolarda eşleştirilmiş Greedy ve Global sonuçlarına dayanır;
bootstrap güven aralıkları, eşleştirilmiş işaret çevirme permütasyon testi, Holm düzeltilmiş
p-değerleri, eşleştirilmiş etki büyüklüğü ve algoritma kazanma oranını raporlar.

Ağ kesintisi ve acil durum talebi katmanları sentetik araştırma stres testleridir; resmî deprem
hasarı veya can kaybı tahmini değildir.

## Español (España)

El flujo de investigación v0.4 separa las grandes campañas Monte Carlo emparejadas de la
aplicación web pública. GitHub Actions puede ejecutar 100, 500 o 1000 realizaciones por nivel de
interrupción y genera CSV, Parquet, metadatos JSON y sumas SHA-256 como artefacto descargable.

La inferencia utiliza observaciones emparejadas de Greedy frente a Global e incorpora intervalos
bootstrap, prueba de permutación por cambio de signo, valores p ajustados con Holm, tamaño del
efecto emparejado y tasa de victorias del algoritmo.

Las capas de interrupción de red y demanda de emergencia siguen siendo pruebas de estrés
sintéticas de investigación, no previsiones oficiales de daños sísmicos ni de víctimas.
