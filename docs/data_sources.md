# Data Sources and Provenance

## AFAD earthquake events
Official source: https://deprem.afad.gov.tr/event-service

Use:
- earthquake catalog ingestion,
- epicenter,
- time,
- magnitude,
- depth,
- scenario selection.

## OpenStreetMap
Official site: https://www.openstreetmap.org/

Use:
- road graph,
- hospitals,
- clinics,
- fire stations.

License:
Open Database License (ODbL). Attribution and share-alike obligations must be reviewed.

## Türkiye Ministry of Health Open Data
Official portal: https://acikveri.saglik.gov.tr/

Potential use:
- health-resource enrichment.

## National Smart Cities Open Data Platform
Official portal: https://ulasav.csb.gov.tr/

Potential use:
- İstanbul traffic,
- municipal geospatial layers,
- emergency-related datasets where available.

## Data manifest standard

Every acquired dataset should record:
- source organization,
- canonical URL,
- retrieval date,
- license,
- geographic coverage,
- temporal coverage,
- raw checksum,
- preprocessing version.
