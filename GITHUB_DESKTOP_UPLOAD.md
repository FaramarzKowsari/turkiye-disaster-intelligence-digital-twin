# Upload with GitHub Desktop

1. Extract the repository folder if you downloaded it as a ZIP.
2. Open GitHub Desktop.
3. Choose **File > Add Local Repository**.
4. Select the folder `turkiye-disaster-intelligence-digital-twin`.
5. If GitHub Desktop says the folder is not yet a Git repository, choose **create a repository here instead**.
6. Use repository name: `turkiye-disaster-intelligence-digital-twin`.
7. Commit the existing files with message: `Initial research-grade disaster digital twin scaffold`.
8. Click **Publish repository**.
9. Keep the repository **Public** if you want it visible in your academic portfolio.

Recommended GitHub description:

> Research-grade AI digital twin for earthquake response in Istanbul and Türkiye using graph optimization, geospatial data, uncertainty modeling, and future multi-agent reinforcement learning.
