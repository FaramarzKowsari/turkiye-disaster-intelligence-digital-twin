# v1.0 Finalization

1. Extract this ZIP into the repository root and allow replacements.
2. Double-click `FINALIZE_V1.cmd`.
   - It removes old `APPLY_*.md` patch notes and other root-level setup clutter.
   - It removes itself after finishing.
3. Open GitHub Desktop.
4. Review the changes.
5. Commit with:

   `Release v1.0 research portfolio`

6. Push origin.
7. Wait for both CI and GitHub Pages deployment to turn green.

After the green v1.0 commit, create the GitHub tag/release `v1.0.0`.
